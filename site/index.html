01

Block poster makers

Turn one image into sheets you can print, trim and assemble.

  • PosterSheet ↗

    Browser tool · maintained by us

    A free block poster maker for JPG, PNG and WebP images. Choose A4, Letter, A3 or custom paper, set margins and overlap, then export a multi-page PDF with optional assembly guidance.

    Image processing stays in your browser. Up to 100 poster sheets; no signup or watermark.

  • The Rasterbator ↗

    Browser tool

    Enlarge an image into a multi-page poster PDF, with halftone styles for wall art.

    Its official FAQ also explains how to select a style without the dot effect.

  • PosteRazor ↗

    Open-source tool

    A wizard-based image-to-poster tool that saves a multi-page PDF. The project offers desktop downloads and a WebAssembly browser version.

    Useful when comparing desktop and browser workflows; check platform compatibility before installing.

02

Image preparation

Prepare the pixels before you decide how large to print.

  • GIMP ↗

    Open-source image editor

    A desktop editor for cropping, retouching and preparing the artwork before it reaches a block poster maker.

    Keep a copy of the original image so you can revise your crop later.

  • GIMP: Print Size ↗

    Official guide

    Explains the relationship between physical print dimensions and image resolution without changing the pixel count.

    Changing the PPI setting alone does not create more image detail.

  • GIMP: Scale Image ↗

    Official guide

    Describes resampling and how changing pixel dimensions affects the image and its memory use.

    Use this to distinguish resizing the pixels from changing the intended print size.

  • ImageMagick ↗

    Open-source command-line tool

    Convert, crop and resize images in repeatable workflows before laying them out for printing.

    Best suited to people comfortable with command-line image processing.

03

Paper, printing and assembly

Choose the right stock and avoid accidentally scaling your tiles twice.

  • Adobe Acrobat: Print posters and banners ↗

    Official printing guide

    Explains Poster printing for an oversized PDF, including tile scale, overlap, cut marks and labels.

    For an already tiled PosterSheet PDF, print at Actual Size / 100% instead of tiling it again.

  • PosterSheet: Print a large image on multiple pages ↗

    Product guide · maintained by us

    A practical entry point for turning an image into a printable PDF and joining its sheets into a larger poster.

    Match the printer paper to the export setting, and test one sheet first.

  • PosterSheet: A4 vs Letter ↗

    Paper reference · maintained by us

    Compare A4 and US Letter dimensions and understand why switching paper sizes changes the printable area.

    A4 is 210 × 297 mm; Letter is 215.9 × 279.4 mm.

  • PosterSheet: Standard poster sizes ↗

    Size reference · maintained by us

    Explore common poster dimensions in inches and centimeters before choosing your final wall size.

    Margins and repeated overlap affect the sheet count, so check the actual export preview.

04

Artwork and reuse guidance

Find printable artwork and read the rights information attached to each item.

  • The Met: Open Access ↗

    Museum collection

    Find public-domain artwork images made available through The Metropolitan Museum of Art's Open Access initiative.

    Choose items marked Open Access and download the full-resolution image.

  • National Gallery of Art: Free images and Open Access ↗

    Museum collection

    A starting point for downloading artwork images available under the National Gallery of Art's Open Access policy.

    Check the individual artwork page and its image availability before planning your poster.

  • Wikimedia Commons: Reusing content ↗

    Reuse guide

    Explains how to reuse Commons images outside Wikimedia, including in print.

    Read each file's license and attribution requirements; the collection does not have one blanket image license.

05

Tools for developers

Building blocks for image previews, PDF output and image processing.

  • pdf-lib ↗

    JavaScript library

    Create and modify PDFs, embed images and draw page content in JavaScript environments, including browsers.

    Useful for generating tiled documents; it is a library, not a ready-made poster layout engine.

  • PDF.js ↗

    PDF rendering library

    Mozilla's web standards-based platform for parsing and rendering PDF documents.

    Useful for previewing exported pages; it does not replace a physical print check.

  • sharp ↗

    Node.js image library

    Image processing for Node.js, including resizing, conversion and compositing.

    Appropriate for build scripts and server-side image workflows, rather than direct browser use.

  • MDN: Canvas tutorial ↗

    Web platform guide

    Learn to draw images and graphics with the browser Canvas API, a useful foundation for poster previews.

    Canvas dimensions and memory limits matter when working with large images.

BEFORE YOU PRESS PRINT

A few small checks.
A better big picture.

Read the complete print guide ↗
  1. Match your paper.

    Use the same size and orientation in the export and your printer settings.

  2. Keep it at 100%.

    Print an already tiled PDF at Actual Size, one page per sheet. Skip the extra tiling.

  3. Test a sheet. Then assemble.

    Check detail and overlap before the full run. Trim the covering edges and align the repeated artwork.
