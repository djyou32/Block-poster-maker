# Block poster printing troubleshooting

[Back to the resource list](../README.md) · [Open PosterSheet](https://postersheet.com/)

| Symptom | Check first | What to try |
| --- | --- | --- |
| Poster is smaller than expected | The PDF viewer may use Fit or Shrink | Choose Actual Size / 100%, matching paper, one PDF page per sheet. |
| One tile becomes several sheets | Poster tiling is enabled on an already tiled PDF | Turn off the extra tiling and print each PDF page once. |
| Edges or trim marks are missing | The margin may be inside the printer's non-printable area | Increase the export margin to suit your printer and test a sheet. |
| Artwork looks soft | The source image may have too few pixels for the printed size | Use a better original or reduce the poster size; test at final scale. |
| White space appears around the image | The image and grid aspect ratios differ | Choose a closer grid ratio or crop the original deliberately in an editor. |
| Sheets will not align | Scaling, orientation or paper settings may differ | Keep the same settings for every page; align repeated artwork, then trim. |
| A blank-looking final sheet appears | Target-size mode can produce partial final tiles | Inspect the preview before printing; distinguish a partial tile from the assembly guide. |
| The guide prints on the wrong stock | The optional guide is A4 | Print only the poster range, then print the guide separately on A4. |
| A large image fails to load | File dimensions or device memory may exceed limits | Stay within 40 MB, 40 MP and 16,000 px per side; try a smaller copy or a device with more memory. |

For a reproducible problem, include the browser, paper size, orientation, grid or target size, margin, overlap and the observed result. You do not need to post a personal photo: use a non-sensitive test image with similar dimensions.

[Open a documentation issue](https://github.com/djyou32/Block-poster-maker/issues) for a broken link or unclear guide. Use [PosterSheet contact](https://postersheet.com/contact) for product support.
