# Block poster maker: your first print

[Back to the resource list](../README.md) · [Open PosterSheet](https://postersheet.com/)

A block poster maker divides an image across ordinary sheets so you can assemble a larger poster with a home printer. PosterSheet creates the tiled PDF; your PDF viewer and printer handle the physical output.

## 1. Prepare your image

Use a JPG, PNG or WebP image you own or have permission to print. Start with the highest-quality original available. Crop it in an image editor first if you want a specific composition. PosterSheet contains the whole image rather than stretching or cropping it; a different grid aspect ratio can leave white space.

## 2. Choose paper and layout

Open [PosterSheet's block poster maker](https://postersheet.com/). Select the paper actually loaded in your printer: A4, Letter, A3 or custom. Choose portrait or landscape and set a grid, or enter a target poster width. Review the final dimensions and sheet count.

Set a margin your printer can reproduce. The overlap repeats a narrow strip of the artwork on neighboring pages to help alignment. The two settings serve different purposes. Trim marks need at least 3 mm of margin; small page labels need 5 mm.

## 3. Export and print

Download the PDF. Open it in a PDF viewer and select:

- The same paper size as the export.
- **Actual Size / 100%** scaling.
- One PDF page per sheet, single-sided.
- Only the poster-page range if you do not want to print the assembly guide.

PosterSheet's optional guide is an additional **A4** page, even when the poster uses another paper size. Print it separately if needed. Do not select Poster tiling on an already tiled PDF: that can divide each tile again. Adobe's [Poster mode](https://helpx.adobe.com/acrobat/desktop/print-documents/booklets-posters-banners/posters-banners.html) is intended for an oversized source PDF that still needs tiling.

## 4. Test, trim and assemble

Print one or two neighboring sheets first. Inspect image quality, margins and the repeated overlap. For dimension-sensitive work, compare a known distance in the print with a ruler before printing the rest.

Lay the pages out in reading order using the preview or assembly guide. Trim the covering edges, align the repeated artwork and secure the joins from behind. Work row by row on a flat surface. The final result depends on printer feed accuracy, paper and trimming; browser checks cannot verify these physical conditions.

## Product boundaries

PosterSheet processes images locally in the browser. It accepts files up to 40 MB, 40 megapixels and 16,000 pixels per side, and exports up to 100 poster sheets. It is not a design editor or an image upscaler. This repository contains the public resource list and documentation; it does not contain the PosterSheet application source.
